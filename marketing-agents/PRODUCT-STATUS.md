# Product status — read before writing anything public

Every agent gets this file in its context. It lists product claims that are
false right now. Public copy (posts, emails, blog drafts, ad creative, site
copy) must not make them, however well they fit a brief.

**This file overrides your task prompt.** Where your prompt asks for price-drop
alerts, buy/wait/hold calls, price trends, price history, or a "set a price
alert" call to action, leave that part out and use what is still true below.
Internal reports may still note that these features are down.

Last checked: 2026-10-01.

## Price tracking is DOWN — since 2026-07-24

No price data has been recorded since July 24. Ticketmaster's API no longer
returns prices for most events, SeatGeek's returns none, and StubHub's login
fails. The tracker runs and saves nothing.

Do NOT claim or imply, in any wording:
- that TicketScan tracks prices, keeps price history, or charts price trends;
- price-drop alerts, target-price alerts, or "we'll tell you when it drops";
- a buy-now signal, buy/wait/hold calls, or "within X% of the low";
- that "our data shows" anything about prices, or any statistic drawn from
  TicketScan price data.

Still true and fine to say:
- TicketScan finds events and shows where to buy them, with links out to
  Ticketmaster and TicketNetwork;
- onsale and presale dates and times;
- venue guides: seating sections, capacity, and tips;
- general, non-TicketScan advice about buying tickets (compare fees, check
  the all-in price, beware of speculative listings).
- Counts from the admin API (users, watchlist items) are real, but "watchlist
  items" are not "events being tracked for price".

When price tracking returns, this section is removed.
