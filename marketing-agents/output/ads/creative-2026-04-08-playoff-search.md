# Ad Creative — 2026-04-08
## Campaign: NBA/NHL Playoff Ticket Comparison (Google Search)

_3 variations for A/B testing. Angle: Playoff urgency + price comparison savings._

---

### Variation A — Price Difference Hook

**Google Search Ad:**
```
Headline 1: Compare Playoff Ticket Prices
Headline 2: Same Seat, $127 Price Gap
Headline 3: Check All 3 Sites Free
Description 1: NBA & NHL playoff tickets priced differently on Ticketmaster, SeatGeek & StubHub. Compare side-by-side.
Description 2: Fans save $40-$80 per ticket by checking all three marketplaces before buying. Takes 90 seconds.
```
- **Final URL:** https://www.ticketscan.io/compare
- **Display path:** ticketscan.io/compare/playoffs
- **Sitelinks:** Price Alerts, Watchlist, World Cup 2026, Venue Guides

**Meta Ad:**
```
Primary text: Same seat. Same row. $127 price difference across Ticketmaster, SeatGeek, and StubHub for first-round playoff tickets. Compare all three before you buy.
Headline: Compare Playoff Tickets Free
Description: See all prices side-by-side
```
- **CTA button:** Learn More
- **Landing:** https://www.ticketscan.io/compare
- **Audience:** Sports fans, 25-54, interest in NBA/NHL + ticket buying
