# Ad Creative — 2026-08-13 — Comparison-led launch set

**Use case:** Initial Google Search and Meta test once tracking and ad accounts are connected.
**Recommended destination:** `/compare`
**Primary angle:** Compare equivalent tickets before checkout.

```text
Headline 1 (30): Compare Ticket Prices
Headline 2 (30): Check 3 Ticket Sources
Headline 3 (30): Compare Before Checkout
Description 1 (90): Compare Ticketmaster, SeatGeek and StubHub for the same event in one place.
Description 2 (90): Skip tab archaeology. See ticket options side by side before choosing a listing.
```

**Meta Ads**


## Test notes

- Primary conversion: `compare_started`; secondary: `signup_completed`, `watchlist_added`.
- Use separate UTMs for each variation: `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`.
- Test one angle at a time for at least 3 days or 100 clicks after instrumentation is live.
- Avoid specific savings, live-price, inventory, or alert-volume claims until verified data is available.
