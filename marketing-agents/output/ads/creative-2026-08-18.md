# Ad Creative — 2026-08-18 — Evergreen comparison tests

**Recommended destination:** `/compare` after anonymous comparison QA  
**Primary conversion:** `compare_started`  
**Secondary conversions:** `signup_completed`, `watchlist_added`

These drafts avoid unsupported claims about savings, live price drops, inventory, user counts, or guaranteed alerts.

### Test notes

- Use unique UTMs for each variation: `utm_source`, `utm_medium`, `utm_campaign`, and `utm_content`.
- Hold each angle for at least three days or 100 clicks after event instrumentation is live.
- Verify the `/compare` anonymous flow before sending paid traffic there; the current login gate interrupts the value proposition.
