# Paid Creative Refresh — 2026-10-05

All variants use supported claims only: event discovery, onsale/presale details, venue guidance, seller links, and general buyer education. They do not claim price tracking, price history, alerts, buy/wait signals, lowest prices, or TicketScan-derived savings.

## Google Search — five variations

### V1 — Event discovery

**Headlines:** Find Your Event | Check Ticket Details | TicketScan  
**Descriptions:** Find the exact event, venue, date, and seller links in one place. Check the details before you choose where to buy.

### V2 — Presale clarity

**Headlines:** Check Presale Details | Verify the Sale Window | Find the Event  
**Descriptions:** Confirm the event, local time, ticket limit, and official sale link before the queue opens.

### V3 — Venue utility

**Headlines:** Know the Venue First | Venue Guides for Fans | Find Your Event  
**Descriptions:** Review seating sections, capacity, event details, and practical venue guidance before event day.

### V4 — Checkout checklist

**Headlines:** Check Before Checkout | Review Ticket Details | Start With the Event  
**Descriptions:** Match the event, section, quantity, delivery terms, and complete order summary before approving payment.

### V5 — Calm preparation

**Headlines:** Plan the Ticket Purchase | Save the Event for Later | TicketScan  
**Descriptions:** Find an event, save it for later review, and keep the onsale or presale details in view.

## Meta — three primary-text/headline combinations

### V6 — Presale checklist

**Primary text:** A presale code gets you into a window. It does not choose the event, seat, delivery method, or final order terms for you. Check those details first.  
**Headline:** The Presale Code Is Not the Plan  
**CTA:** Learn more

### V7 — Venue preparation

**Primary text:** Before event day, check the exact venue, section names, entry details, and official event page. A few minutes of context can make the whole ticket decision clearer.  
**Headline:** Know the Venue Before You Go  
**CTA:** Find an event

### V8 — Like-for-like review

**Primary text:** Different listings are not useful comparisons unless the event, section, quantity, delivery, and order terms match. Start with the exact event, then check the details.  
**Headline:** Compare the Ticket Details  
**CTA:** Learn more

## Display / social image concepts — three variants

### V9 — Presale window card

**On-image copy:** Confirm the event. Check the time zone. Read the rules.  
**Visual direction:** Clean ticket-stub and clock motif; three checklist rows; no countdown timer or scarcity language. CTA: “Find the event.”

### V10 — Venue guide card

**On-image copy:** Event day starts before the gate.  
**Visual direction:** Simplified stadium/arena outline with section, entry, and transit callouts; use a real verified venue only when the destination matches.

### V11 — Checkout review card

**On-image copy:** Event. Section. Quantity. Delivery. Total.  
**Visual direction:** Five-field checklist on a neutral white card; no sample prices, fake logos, or “lowest price” badges. CTA: “Check before checkout.”

## Testing framework

- Test one variable at a time: headline, primary text, image, or audience.
- Use `utm_content=v1` through `v11`.
- Run each variant for at least three clean attributed days or 100 clicks, whichever comes later.
- Primary decision metric is qualified conversion, not CTR alone.
- Pause or scale only after the account owner supplies a target CPA and the conversion events are verified.
