# Comparison Page Spec: TicketScan vs. Gametime

**Owner:** Content Agent  
**Path:** `/compare/ticketscan-vs-gametime`  
**Status:** Ready for a sourced draft; do not publish until product-status review.

## Search Intent

Users deciding between a neutral ticket-research workflow and a mobile-first, last-minute resale marketplace.

## Recommended Positioning

“TicketScan helps you research the event, venue, and onsale timing. Gametime is built for buying resale tickets quickly, especially close to event time.”

## Feature Matrix

| Capability | TicketScan | Gametime |
|---|---|---|
| Event discovery | Yes; supported event feeds | Yes; marketplace inventory |
| Venue guides | Yes; seating, capacity, and practical tips | Venue maps and seat-view tooling in app listing |
| Onsale/presale information | Yes | Not the primary value proposition |
| Watchlist | Yes; save events for revisiting | App supports ticket buying/selling workflows |
| Native mobile app | No verified native app | Yes |
| Last-minute / post-start purchase | Not a TicketScan claim | App listing says up to 90 minutes after start |
| Buyer protection | Do not claim transaction guarantee | Ticket Coverage and protection claims; restrictions apply |
| Ticket delivery | Links to sellers; delivery is seller-specific | Mobile delivery and Ticket Tracker claims |
| Live TicketScan price history, alerts, or buy/wait advice | Currently unavailable; omit from public copy | Not a TicketScan comparison claim |

## Page Outline

1. Short answer and disclosure: TicketScan is a research/discovery product; Gametime is a resale marketplace.
2. How TicketScan works: search an event, review verified venue/onsale information, save it, and follow a seller link when ready.
3. How Gametime works: mobile-first resale purchase, seat views, all-in pricing, post-start purchase, and buyer-protection messaging.
4. Feature matrix above.
5. Decision guide:
   - Planning a purchase or learning a venue → TicketScan.
   - Buying close to event time in a mobile flow → Gametime.
6. Buyer checklist: compare the final all-in total, confirm date/venue/section, read delivery and refund terms, and avoid speculative listings.
7. Sources and affiliate/editorial disclosure.

## SEO and Internal Links

- Link to relevant venue guides, city/category pages, onsale pages, FAQ, and event discovery.
- Use supporting anchors such as “venue seating guide,” “onsale date,” and “compare ticket fees.”
- Avoid unsupported superlatives such as “cheapest,” “best prices,” or “better protection.”
