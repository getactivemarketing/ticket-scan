# Handoffs — Content Agent 1 and CRO Agent 6

## Content Agent 1: new briefs

1. **Ticket price comparison methodology**
   - Intent: compare Ticketmaster vs. SeatGeek vs. StubHub.
   - Must answer: same-seat matching, base vs. all-in price, fee estimates, timestamp, buyer protection, and why listings change.
   - Links: `/compare`, `/how-it-works`, `/faq`, representative venue/city guides.

2. **Best time to buy tickets, with evidence**
   - Intent: timing advice for concerts and sports.
   - Must distinguish regular-season, playoffs, high-demand onsales, and last-minute inventory.
   - Use TicketScan historical data only when sample size and date windows are shown; avoid universal “2–3 weeks” claims.

3. **2026 World Cup ticket lessons and venue archive**
   - Intent: evergreen post-event research and future tournament planning.
   - Update future-tense language, preserve official-vs-resale and venue guidance, and link to the 16 stadium pages.

4. **City ticket hubs**
   - Start with New York, Los Angeles, Chicago, Miami, and Orlando.
   - Compare local venues and event categories; include useful transportation/venue context only when sourced and current.

5. **Ticket fees explained**
   - Include disclosure that estimates vary by event, delivery method, and marketplace; link to the live comparison experience.

## CRO Agent 6: landing-page requests

- Venue pages: place “Compare current prices” and “Set a price alert” above the fold or immediately after the first event module.
- City/category pages: use a sticky or repeated CTA after event cards; show the benefit before asking for registration.
- FAQ/how-it-works: add a clear path from answer → search → watchlist.
- Empty/stale results: replace dead-end messaging with newsletter/watchlist capture and a visible last-checked timestamp.
- Comparison page: test fee-inclusive total as the primary number and marketplace/source as the secondary detail.

## Acceptance criteria

- No page labels past events as upcoming.
- Every dynamic price claim has timestamp and estimate/live label.
- All handoff pages have a measurable CTA event for search, registration, newsletter, and watchlist.
- Content updates include `updatedAt` and a source/methodology reference.
