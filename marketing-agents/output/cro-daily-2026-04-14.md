## Tuesday Focus: Compare Page (`/compare`)

### Critical Issues (P0)

**1. Hard login gate kills anonymous conversion**
- Current: `if (!user) router.push('/login')` — silent redirect, no teaser
- Impact: Every anonymous visitor who reaches Compare bounces with no value shown
- Fix: Show a blurred/limited preview of comparison results with an overlay CTA: "Sign up free to unlock full price comparisons." Let them search, show 1-2 matched results, then gate the rest. This converts curiosity into signups instead of bouncing it.
- Effort: Medium (2-3 hours)

**2. No watchlist CTA on comparison results**
- Current: Matched event cards show "Buy on Ticketmaster" and "Buy on SeatGeek" — both exit the site immediately
- Impact: Users who find a good deal leave without creating a trackable relationship
- Fix: Add "Track This Event" button on each matched result card, linking to watchlist add flow
- Effort: Low (1 hour)

**3. Internal API status exposed to users**
- Current: SeatGeek empty state shows `(API may be pending approval)` 
- Impact: Erodes trust — users see infrastructure issues instead of a graceful empty state
- Fix: Replace with "Results from additional sources coming soon" or remove entirely
- Effort: Trivial (5 minutes)

### High-Impact Issues (P1)

**4. Hardcoded default city "Orlando"**
- Current: City field pre-fills with "Orlando" on both Dashboard and Compare
- Impact: Users in other cities must actively clear and retype — adds friction and confusion
- Fix: Empty default with placeholder text, or use browser geolocation API to suggest
- Effort: Low (30 minutes)

**5. No StubHub column despite multi-source promise**
- Current: Page header implies broad comparison but only shows Ticketmaster vs SeatGeek
- Impact: Undermines the "compare across 5+ sites" value prop from the homepage
- Fix: Add StubHub column when credentials are available; meanwhile, show "StubHub — Coming soon" to set expectations
- Effort: Medium

**6. Value proposition unclear above the fold**
- Current: Search form is the first thing users see — no heading explaining what Compare does or why it's valuable
- Fix: Add a brief heading above the form: "See the same event across every ticket site — find who has the best price"
- Effort: Trivial (15 minutes)

### Medium Issues (P2)

**7. "All Events" view UX problems**
- Two scrollable 600px columns are unusable on mobile
- Matched events are mixed in with unmatched — no clear visual hierarchy
- Fix: Stack columns on mobile; visually separate matched from unmatched with section headers

**8. No loading skeleton**
- Just a spinner during search — causes layout shift when results appear
- Fix: Skeleton cards matching result layout

**9. Pro Tip banner shows before any search**
- The amber SeatGeek fee disclaimer is always visible, even pre-search
- Fix: Only show after results load, contextually near SeatGeek prices
