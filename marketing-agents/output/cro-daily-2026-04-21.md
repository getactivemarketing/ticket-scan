### P0 (new critical) — Structured-data / reality mismatch on `/compare`

The weekend landed `web/src/app/compare/layout.tsx` (currently untracked in `git status`). It adds a `WebApplication` JSON-LD block that declares the page as an interactive comparison tool with this public `featureList`:

```json
"featureList": [
  "Side-by-side price comparison across Ticketmaster and SeatGeek",
  "All-in fee-inclusive pricing (Ticketmaster ~27%, SeatGeek ~20%)",
  "Estimated section breakdowns (upper/lower/club/floor) at 24 major venues",
  "Savings callouts showing dollar difference between platforms",
  "Filter by city, artist, team, and date range"
]
```

There is a `"price": "0"` offer attached. Googlebot will index this, potentially build rich results around it, and send organic traffic to a page that — for every anonymous visitor — redirects to `/login` before rendering any of the advertised functionality.

**Consequence chain:**

1. We are now telling Google (and potentially Bing, Perplexity, ChatGPT Search, Copilot) that `/compare` is a free, interactive web application.
2. Google's quality raters consider "content parity with what was advertised in SERP" a core ranking signal. A user clicking a rich result and getting a login wall is a **classic doorway/cloaking pattern** — the same structured data that makes the listing appealing is the structured data that lies about what's behind the click.
3. This is now actively working against the SEO investment Agent 4 is making every day.
4. This lands on a page that *also* hard-gates. The JSON-LD was added without reconciling against the access model.

**Fix options:**

**Option A (30 min, minimal):** Add `"requiresAuthentication": true` to the `WebApplication` node, OR remove the `WebApplication` node entirely until the page ungates. Keep the `BreadcrumbList`. This at least stops lying to crawlers.

**Option B (3 hrs, recommended — also solves the 7-day-old problem):** Ungate the page. Render the full comparison UI for anonymous users and replace the auth gate with a **single-use trial + capture**:
- Anonymous users get 3 free comparisons per IP/device-fingerprint/localStorage counter.
- On 4th compare, show a modal: "Sign up free to keep comparing." Same model as `EventCard`'s recently-shipped watchlist modal.
- JSON-LD now matches reality — anonymous user really does experience the advertised features.

**Option C (1 hr):** Soft-gate only the advanced features. Ungate basic search + side-by-side compare; gate "save this comparison" / "alert me when price drops" behind auth. Freemium model, honest to structured data, converts at intent.

Option B is the right answer and has been the right answer for 7 days. Option A is the 30-minute backstop if B is not prioritized this sprint.

**Effort:** 30 min (A) / 3 hrs (B) / 1 hr (C). **Impact:** Option A stops SEO damage. Option B is ~40–60% signup lift from Compare-traffic segment (per last week's estimate) AND removes the risk of Google penalty for content-parity violation.

`compare/page.tsx:74` — `useState('Orlando')`. Same as dashboard. Same issue flagged repeatedly on `/dashboard`. A user in NYC searching for Rangers games sees Orlando pre-filled, is confused by the mismatch, and either:

```tsx
const [city, setCity] = useState('');

  const cached = localStorage.getItem('ticketscan:lastCity');

```

**Effort:** 15 min (blank default) / 45 min (localStorage memory). **Impact:** Estimated +8–15% search completion on first-time traffic (users not in Orlando). Low risk — placeholder copy already explains the input.

### P0 — `/login` page is blind about the `/compare` redirect

`web/src/app/login/page.tsx:36–43`. When a user is bounced from `/compare` to `/login`, the login page renders exactly "Welcome back" + "Sign in to your Ticket Scan account." A user who has **never been to our site before** sees a page that says "Welcome back" and asks them to sign in — confusing at best, feels broken at worst.

The gate redirect is also a *terminal* event for anonymous users: no query param is preserved, no explanation is given, and no "create account" path is offered except the footer link.

**Fix (minimum viable, ~30 min):**

1. Pass the source in the redirect:

```tsx
// compare/page.tsx:87–90
if (!authLoading && !user) {
  router.push('/login?from=compare');
  return null;
}
```

2. On the login page, read the param and conditionally render context:

```tsx
const searchParams = useSearchParams();
const from = searchParams.get('from');
const contextMessage = {
  compare: 'Sign in to compare ticket prices across Ticketmaster and SeatGeek.',
  watchlist: 'Sign in to track this event and get price drop alerts.',
  event: 'Sign in to see event details and set a price alert.',
}[from ?? ''] ?? null;

// In JSX:
{contextMessage && (
  <div className="bg-brand/10 text-brand-dark p-3 rounded-lg text-sm mb-4">
    {contextMessage}
  </div>
)}
<h2>{from ? 'Sign in to continue' : 'Welcome back'}</h2>
```

3. On successful login, return the user to the source page, not blindly to `/dashboard`:

```tsx
await login(email, password);
const returnTo = searchParams.get('returnTo') || '/dashboard';
router.push(returnTo);
```

And on `/compare`, pass the return:

```tsx
router.push('/login?from=compare&returnTo=/compare');
```

**Effort:** 45 min. **Impact:** This does not lift the gate — but it makes the gate slightly less hostile. Even if Option A/B/C above are not prioritized, this P0 is worth shipping because it's cheap and the return-to-source pattern unblocks *every* future gated surface.

### Recommended fix (minimum viable — ~1 hr)

```tsx
'use client';

import { useState } from 'react';
import { useRouter, useSearchParams } from 'next/navigation';
import Link from 'next/link';
import { useAuth } from '@/context/AuthContext';
import Logo from '@/components/Logo';

const COMMON_EMAIL_TYPOS: Record<string, string> = {
  'gmial.com': 'gmail.com',
  'gmai.com': 'gmail.com',
  'gmal.com': 'gmail.com',
  'yahooo.com': 'yahoo.com',
  'yaho.com': 'yahoo.com',
  'hotmial.com': 'hotmail.com',
  'outllook.com': 'outlook.com',
};

export default function RegisterPage() {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [showPassword, setShowPassword] = useState(false);
  const [error, setError] = useState('');
  const [emailHint, setEmailHint] = useState('');
  const [loading, setLoading] = useState(false);
  const { register } = useAuth();
  const router = useRouter();
  const searchParams = useSearchParams();
  const source = searchParams.get('source') || 'direct';
  const returnTo = searchParams.get('returnTo') || '/dashboard';

  const checkEmailTypo = (value: string) => {
    const domain = value.split('@')[1]?.toLowerCase();
    if (domain && COMMON_EMAIL_TYPOS[domain]) {
      const fixed = value.replace(domain, COMMON_EMAIL_TYPOS[domain]);
      setEmailHint(`Did you mean ${fixed}?`);
    } else {
      setEmailHint('');
    }
  };

  const passwordStrength = (pw: string): { score: 0 | 1 | 2 | 3 | 4; label: string } => {
    if (pw.length < 8) return { score: 0, label: 'Too short' };
    let score = 1;
    if (pw.length >= 12) score++;
    if (/[A-Z]/.test(pw) && /[a-z]/.test(pw)) score++;
    if (/[0-9]/.test(pw) && /[^A-Za-z0-9]/.test(pw)) score++;
    const labels = ['Too short', 'Weak', 'Okay', 'Good', 'Strong'] as const;
    return { score: Math.min(score, 4) as 0 | 1 | 2 | 3 | 4, label: labels[Math.min(score, 4)] };
  };

  const strength = passwordStrength(password);

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setError('');
    if (password.length < 8) {
      setError('Password must be at least 8 characters');
      return;
    }
    setLoading(true);
    try {
      await register(email, password, { source });
      router.push(returnTo);
    } catch (err) {
      setError(err instanceof Error ? err.message : 'Registration failed');
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className="min-h-screen flex items-center justify-center bg-gray-50 py-12 px-4 sm:px-6 lg:px-8">
      <div className="max-w-md w-full">
        <div className="bg-white rounded-2xl shadow-xl p-8">
          <div className="text-center mb-8">
            <Logo size={40} />
            <h2 className="mt-4 text-3xl font-bold font-heading text-gray-900">
              Start saving on tickets
            </h2>
            <p className="mt-2 text-gray-600">
              Price alerts, cross-site comparison, and section-level estimates — free.
            </p>
          </div>

          <form onSubmit={handleSubmit} className="space-y-5" noValidate>
            {error && (
              <div className="bg-red-50 text-red-600 p-3 rounded-lg text-sm" role="alert">
                {error}
              </div>
            )}

            <div>
              <label htmlFor="email" className="block text-sm font-medium text-gray-700 mb-2">
                Email address
              </label>
              <input
                id="email"
                type="email"
                autoComplete="email"
                required
                value={email}
                onChange={(e) => { setEmail(e.target.value); checkEmailTypo(e.target.value); }}
                className="w-full px-4 py-3 border border-gray-300 rounded-lg focus:ring-2 focus:ring-brand focus:border-transparent outline-none"
                placeholder="you@example.com"
              />
              {emailHint && (
                <button
                  type="button"
                  onClick={() => {
                    const domain = email.split('@')[1]?.toLowerCase();
                    if (domain && COMMON_EMAIL_TYPOS[domain]) {
                      setEmail(email.replace(domain, COMMON_EMAIL_TYPOS[domain]));
                      setEmailHint('');
                    }
                  }}
                  className="mt-1 text-xs text-brand hover:text-brand-dark"
                >
                  {emailHint} ← click to fix
                </button>
              )}
            </div>

            <div>
              <label htmlFor="password" className="block text-sm font-medium text-gray-700 mb-2">
                Password <span className="font-normal text-gray-500">(8+ characters)</span>
              </label>
              <div className="relative">
                <input
                  id="password"
                  type={showPassword ? 'text' : 'password'}
                  autoComplete="new-password"
                  required
                  value={password}
                  onChange={(e) => setPassword(e.target.value)}
                  className="w-full px-4 py-3 pr-12 border border-gray-300 rounded-lg focus:ring-2 focus:ring-brand focus:border-transparent outline-none"
                />
                <button
                  type="button"
                  aria-label={showPassword ? 'Hide password' : 'Show password'}
                  onClick={() => setShowPassword(!showPassword)}
                  className="absolute right-3 top-1/2 -translate-y-1/2 text-gray-500 hover:text-gray-700"
                >
                  {showPassword ? '🙈' : '👁'}
                </button>
              </div>
              {password && (
```
