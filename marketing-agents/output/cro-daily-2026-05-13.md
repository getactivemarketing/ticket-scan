#### P0 (NEW today) — **The watchlist-add button is the single highest-trust action on the platform, and the API client + DB are *more capable* than the UI uses.** This is the rarest defect in a CRO audit: not "the spec is missing" but "the spec is implemented on the server, ignored on the client."

The 4/22 P0 (W1 above) noted the `targetPrice` omission. Today's framing escalates to **what the gap costs across the rest of the funnel:**

1. **Every watchlist row is product-broken at insert time.** No row has ever had a `target_price`. The cron checks `currentPrice <= NULL` (which is `NULL`, falsey) for every row — **the entire price-drop alert pipeline has produced zero emails since launch.**
2. **The drip campaign Email 2 ("How Price Alerts Can Save You Hundreds") is sent on Day 7 to users whose watchlist rows have no target.** The drip body promises a feature that, for the receiving user, has never functioned. Day 24 of this content-parity violation in the drip pipeline (separate from the source-table bug).
3. **The dashboard `featureList` schema-lie** (finding #13 above) advertises target-price capture; the EventCard refuses to capture; the cron checks NULL; the drip promises alerts. **Four surfaces — schema, UI, cron, email — are all out of sync with each other, and the chain is broken at the second hop.**

**Fix (the inline-input variant, ~30 min):**

```tsx
// EventCard.tsx, add to state:
const [showTargetInput, setShowTargetInput] = useState(false);
const [targetPrice, setTargetPrice] = useState<string>('');

// In handleAddToWatchlist, replace the immediate POST with:
if (!showTargetInput) {
  setShowTargetInput(true);
  return;
}
// then submit with: targetPrice: targetPrice ? Number(targetPrice) : undefined

// JSX: between the price display and the button row, add:
{showTargetInput && !added && (
  <div className="mt-3 flex gap-2">
    <input
      type="number"
      inputMode="decimal"
      placeholder={`Alert me at $${event.priceRanges ? Math.floor(event.priceRanges.min * 0.9) : '50'}`}
      value={targetPrice}
      onChange={(e) => setTargetPrice(e.target.value)}
      className="flex-1 px-3 py-2 border border-gray-300 rounded-lg text-sm"
      autoFocus
    />
  </div>
)}
```

The button label switches to "Set Alert" when `showTargetInput && !added`. The first click toggles the input; the second click submits. **Two-click pattern adds one tap but captures the data the drip campaign promises.**

**Impact:** First time the price-drop alert pipeline fires for any user. Single biggest end-to-end product-completion ship available on the platform — closes the schema/UI/cron/drip parity chain in one commit.
