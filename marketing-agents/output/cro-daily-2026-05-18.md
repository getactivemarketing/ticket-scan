### What's new today on the homepage (Day +7 from 5/11, Day +14 from 5/4)

#### P0 (NEW today) — **`HomeHeroButtons` component is imported but never rendered; the homepage hero uses hard-coded `<Link>`s instead, breaking auth-state-aware CTA copy.**

`page.tsx:3` imports `HomeHeroButtons`. `grep -n "HomeHeroButtons" web/src/app/page.tsx` returns **only the import line.** The hero CTAs at `:82–85` are hard-coded:
```tsx
<Link href="/register">Get Started Free</Link>
<a href="#how-it-works">See How It Works</a>
```

But `HomeHeroButtons.tsx:19–46` has *both* a logged-in state (`Search Events` button → `/dashboard`) and a logged-out state (`Find Tickets` + `Login` buttons). **The component was written to make the homepage hero auth-aware, then never used.** A user who is already logged in (the 84 existing users, presumably some returning) sees "Get Started Free" — pushing them to re-register. **This is a 2-line fix** (delete the hard-coded block, render `<HomeHeroButtons />` instead) that ships a meaningful UX improvement for the small returning-user cohort.

**Effort:** 2 min. **Composes with:** the `?returnTo=` cluster (HomeHeroButtons can take `source="hero-cta-logged-in"` props in a future iteration); the dead-import lint hygiene (NEW P2 #4 below covers this from the lint angle).

**Tradeoff:** the hard-coded version has "Get Started Free" (more conversion-optimized copy than the component's "Find Tickets"). If `HomeHeroButtons` is wired up, the logged-out copy should be updated to "Get Started Free / See How It Works" to match the design intent. **Effort with copy parity: 5 min.**

#### P0 (NEW today) — **The two homepage NewsletterSignup mounts produce `source="homepage"` + `source="footer"` writes, but the daily subscriber count stays at 3. Either the source column is not being read, OR no one is converting on either surface.**

Live admin API confirms `activeSubscribers: 3` flat for 8 days. The platform's only email-capture surfaces both ship on `/`. **Either:**

(a) **Homepage traffic is too low to convert any visitor** — possible given organic SEO traffic to the homepage specifically (vs. venue/city/WC SEO landings which actually have indexable content) is likely 5–20 sessions/day. The platform's traffic shape doesn't push users to `/`; it pushes them to long-tail landings that have zero email capture.

**Without telemetry (Day 41), neither hypothesis is testable.** But the audit's accumulated evidence strongly suggests (a): zero email captures over 8 days × 84 registered users implies that NONE of the 84 register flows passed through a newsletter capture either. **Effort:** the structural fix is the global Footer migration (H10, 30 min). With NewsletterSignup mounted in `Footer.tsx`, the ~100 non-homepage SEO surfaces gain an email capture surface above the bottom of the page. **Cost-of-delay: every day the global Footer is unfixed, ~100 cold-traffic landings ship with zero email-capture path.
