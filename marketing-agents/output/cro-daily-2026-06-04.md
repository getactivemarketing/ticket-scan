## Form Friction Check — User registration (`register/page.tsx`)

A clean, conventional 3-field form. Minimal and uncluttered; the issues are small polish + autofill, not structural.

| Check | Status | Note |
|-------|--------|------|
| Field count | ⚠️ **3** | email, password, **confirm-password** (`:95–108`). The confirm field is the one removable field — modern flows drop it in favor of a show/hide toggle, cutting a third of the typing. |
| Field labels | ✅ | Clear, associated `htmlFor`/`id`, good placeholders. |
| Email keyboard | ✅ | `type="email"` (`:71`) → correct mobile keyboard. |
| **autoComplete attrs** | ❌ **Absent** | No `autoComplete` on any field. Password managers / browser autofill won't reliably offer to fill or save. Add `autoComplete="email"`, `autoComplete="new-password"` (both password fields). Cheap, real signup-completion lift. |
| Show/hide password | ❌ None | No reveal toggle; combined with a hidden confirm field, typo risk is the main abandonment driver here. |
| Password requirements | ⚠️ Late | "min 8 chars" only surfaces **after** submit as an error (`:27–29`). Show the rule inline under the field before the user submits. |
| Submit copy | ✅ | "Create account" / "Creating account…" (`:115`) — action-oriented, has a loading state. Good. |
| Error feedback | ✅ | Inline red box (`:59–63`); messages are specific ("Passwords do not match", min-length). |
| Value reminder | ⚠️ Thin | "Start tracking ticket prices today" (`:54`) is fine but carries no proof. A one-line benefit ("Free price alerts across Ticketmaster & SeatGeek") would reinforce at the commitment point. |
| Conversion telemetry | ❌ None | No event on submit/success — same measurement gap as everywhere. |

**Form recommendations:**
1. **🟡 Add `autoComplete` attributes** (`email`, `new-password`) to all three fields — best effort:reward ratio for signup completion; ~5 min.
2. **🟡 Add a show/hide password toggle and drop or de-emphasize the confirm field** — removes a field and the top typo-abandonment cause; ~20 min.
3. **🟢 Surface the 8-char rule inline** under the password field (not just on error); ~5 min.
4. **🟢 One benefit line** under the heading reinforcing what they get; copy → Agent 1.
