## Page-Level Conversion Review — `/dashboard`

### What is working

- The primary task is clear above the fold: “Search Events.”
- The form has four understandable filters: city, event/artist/team, from date, and to date.
- `Search Events` is a visible, action-oriented button and the form submits on Enter.
- The responsive grid collapses to one column on small screens; fields have comfortable touch-target padding.
- Anonymous visitors can browse/search and see a signup banner explaining the benefit of tracking prices.

### Recommendations

1. **P0 — Instrument the dashboard funnel.** Emit `dashboard_viewed`, `search_started`, `search_completed`, `search_zero_results`, `event_card_viewed`, `watchlist_started`, `signup_started`, and `signup_completed`. Include route, auth state, device, result count, and CTA variant; never include raw email or full search text.

2. **P1 — Make the first action more outcome-led.** Change `Search Events` to **“Find Ticket Prices”** or **“Compare Ticket Prices”** when the endpoint actually returns cross-source comparison data. Keep the current wording only if the dashboard is intentionally browse-only; the current copy undersells the product’s differentiator.

3. **P1 — Replace the icon-only watchlist action on event cards.** Anonymous cards currently expose an eye icon with a tooltip and a generic `Sign Up Free` overlay. Add a visible secondary CTA: **“Get price-drop alerts”**, preserve the event/query context into registration, and show target-price setup immediately after account creation.

4. **P2 — Improve zero-result recovery.** Add one-click options to remove the date filter, broaden the date range, or browse popular upcoming events. The current “Try a different city, keyword, or date range” message makes the user do all the recovery work.

### Form recommendation — P0

When registration follows an event/alert action, use contextual copy:

```text
Heading: Create your free price alert
Supporting copy: We’ll watch this event and email you when prices hit your target.
Primary button: Create account & set alert
After signup: Account created. Set your target price to start tracking.
```

Preserve a validated return URL and event context through signup, then show a one-screen target-price step. Add `signup_started`, `signup_completed`, `target_price_set`, `onboarding_skipped`, and `watchlist_added` events. Add `role="alert"` to error feedback and `autoComplete="email"` to the email field.
