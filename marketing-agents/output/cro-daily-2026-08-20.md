## Form Friction Check

### Focus form: Watchlist add / price-alert setup

There is no standalone watchlist-add modal in the current code. `EventCard` uses a one-click add for authenticated users and a sign-up overlay for logged-out users. Neither path collects `targetPrice`; the event-detail page also has no target-price form.

Improvement specification:

- Keep the first step to one optional numeric field: “Alert me at $___ or less”.
- Use `type="number"`, `inputMode="decimal"`, `min="0"`, and a dollar prefix; reject negative or non-numeric values with an inline message.
- Replace the icon-only authenticated action with a labeled button: **“Track & set alert”**. Keep “Track without alert” as a secondary link for users who are not ready.
- On submit, show **“Saving your alert…”**, then confirm the saved target and the next price-check expectation.
- If the API rejects a duplicate event, explain that it is already tracked and offer **“Edit alert”** instead of a generic failure.
- For logged-out users, retain the event payload through registration so they return to the alert form rather than restarting the search.
