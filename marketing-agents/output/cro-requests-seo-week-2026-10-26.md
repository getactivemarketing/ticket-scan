# CRO requests from SEO audit — 2026-10-26

## P0: align promise with deliverable

Audit every homepage, footer, venue, World Cup, how-it-works, blog, and
newsletter CTA. Replace unsupported alert/price language with one of these
verifiable actions:

- Search upcoming events
- Browse venue guides
- Check onsale and presale dates
- Save an event to revisit
- Review the seller’s current checkout page

If the newsletter currently sends onsale information, name that exact cadence
and content. If it does not, pause the form rather than promising alerts.

## P1: improve conversion clarity

- Put affiliate disclosure immediately beside the first outbound seller CTA.
- On event cards, label “Price TBA” plainly and avoid nearby copy that implies
  TicketScan has current price coverage.
- For no-event states, link to the city hub, venue guide, and onsale calendar.
- Replace “best deals” and “never overpay” with concrete, supportable benefits:
  event discovery, venue context, and onsale timing.

## P1: accessibility

Change low-contrast status, venue, and date tokens to WCAG AA-compliant colors;
rerun mobile axe/Lighthouse and verify keyboard focus on seller links, save
buttons, and signup controls.

## Success metrics

Track search-to-event click, outbound seller click, venue-guide click,
onsale-calendar click, newsletter completion, and account registration. Do not
use price-alert or price-savings events until the underlying product is live
and validated.
