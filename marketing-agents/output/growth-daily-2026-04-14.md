## Psychology-driven micro-optimization

### Today's principle: FOMO (fear of missing out)

**Rotation:** Commitment/Consistency (Apr 8), Social Proof (Apr 10), Scarcity (Apr 11), Loss Aversion (Apr 12), Reciprocity (Apr 13). Today: FOMO.

**Where:** Search results and event cards -- the moment a user is browsing but hasn't committed

**The problem:** When a user searches for an event on TicketScan, every result looks the same. Static cards, static prices. There's no signal that says "other people are paying attention to this" or "prices have been moving." Nothing creates the feeling that waiting costs you something.

**Current state:** Event cards show event name, date, venue, and a compare button. No price movement data, no popularity signals, no time-based urgency. A user can browse results and feel zero pressure to act.

**Proposed change:** Add a "price activity" line to event cards in search results:

On each event card, below the venue/date line:
```
[down arrow] 3 price drops this week  |  Watched by 4 people
```

Or, if prices went up:
```
[up arrow] Prices up 12% since last week  |  Watched by 2 people
```

For events with no price history yet:
```
Be the first to track this event
```

**Why this works:**
- FOMO operates on the gap between "what I have" and "what I could miss." Showing price drops that already happened tells the user they missed savings. Showing price increases tells them waiting is costing money.
- "Watched by X people" is social proof layered on top of FOMO -- other people are already doing the thing you haven't done.
- "Be the first" flips scarcity around -- instead of missing out on a deal, you're missing out on being early.
- None of this requires fake data. Price history is already tracked every 4 hours. Watchlist counts are a simple database query.

**Implementation:**
- Query `price_history` for 7-day price movement per event in search results
- Query watchlist count per event_id (already available via admin API)
- Add a `PriceActivity` sub-component to `EventCard.tsx`
- Show conditionally based on data availability
- Track click-through rate: cards with FOMO line vs. without

**Expected impact:**
- Search result -> watchlist add conversion: +15-25%
- Target price setting (if combined with scarcity prompt from Apr 11): +10%
- This fills a gap in the psychology funnel -- reciprocity (Apr 13) drives signup, FOMO drives the first watchlist add, scarcity drives target price setting, loss aversion drives purchase
