# Psychology optimization — 2026-10-09

## Principle: commitment and consistency

**Where:** Post-signup dashboard and empty watchlist state.

**Exact UX change:** Add a three-step progress cue:

`1. Find an event → 2. Save it to your list → 3. Check dates, sellers, and venue tips`

On the empty state, use:

> Your list is empty. Save one event to make your next ticket search easier.

Primary button: **Find an event**

Secondary helper copy: **You can remove it anytime.**

**Expected impact:** Reduce the activation gap by making the first useful action explicit and low-commitment. This is a hypothesis, not a measured result; validate with signup-to-first-watchlist-add conversion and a 7-day return rate.

**Guardrail:** Do not describe the list as price tracking or promise alerts. The value proposition is saved-event organization plus event links, onsale/presale timing, and venue guidance.
