## Psychology Optimization — 2026-08-08

**Principle:** Commitment and consistency.

**Where:** Post-registration onboarding and the empty watchlist state.

**Exact UX change:** Replace a generic empty state with:

> You’re 1 step from your first price alert
>
> Add an event to your watchlist. We’ll track prices while you get on with your day.

Use one primary CTA: **Find an event to track**. After the first add, show a completed step and the next action: **Your first alert is set — compare prices now**.

**Expected impact:** Hypothesis: a 5–10% relative lift in registration-to-first-watchlist conversion. Validate with an A/B test; this is not an observed result.

**Measurement:** Track registration → empty state view → event search → first watchlist add → target-price alert set. Primary metric is first watchlist add within 24 hours; guardrail is unsubscribe rate.
