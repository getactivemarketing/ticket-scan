# Psychology Optimization — 2026-08-15

## Recommendation

**Principle:** Commitment and consistency.

**Where:** Post-signup dashboard empty state and first-watchlist flow.

**Exact UX copy:**

> You’re 1 step from your first price alert
>
> Search an event → Add it to your watchlist → Set a target price
>
> Find an event to track

After the first watchlist add, change the message to: **“Nice. One more step: set the price you’d actually pay.”** Keep one primary CTA and make completion state visible.

**Expected impact:** Test for a 5–10% relative lift in signup-to-first-watchlist conversion. Primary metric: watchlist add within 24 hours. Secondary: target price set within 7 days. Guardrail: unsubscribe rate.

Rationale: 8 of 15 users in the current seven-day signup cohort have no watchlist item. A visible, finite next step gives those users a concrete action without manufacturing urgency or unsupported scarcity claims.
