# Psychology Optimization — 2026-10-20

## Principle

Endowment effect, supported by commitment and consistency: once a user feels an event is “theirs,” returning to it requires less effort than starting a new search.

## Placement

- Event cards immediately after a successful search.
- The empty saved-events state after signup.

## Exact copy and UX

Event card helper text:

> Save this event so it’s ready when you are. We’ll keep the date, venue, onsale details, and official ticket links together in your saved events.

Button: **Save this event**

Empty state:

> Your first saved event is one search away — try a team, artist, venue, or city.

Primary action: **Find an event to save**

## Expected impact and test

The change should reduce uncertainty about what saving does and shorten the path from signup to a first meaningful action. Test against the current copy using signup-to-first-saved-event conversion, first-session saves, and seven-day return rate. Do not claim an uplift percentage before the site has event instrumentation and a measured baseline.
