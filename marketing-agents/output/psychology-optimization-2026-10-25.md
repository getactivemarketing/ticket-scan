# Psychology Optimization — 2026-10-25

**Principle:** endowment effect, reinforced by commitment and consistency.

**Touchpoint:** post-signup saved-events empty state and the first event card.

**Exact copy:**

> Your first saved event is one search away. Save the date, venue, onsale details, venue guide, and official ticket links in one place.

Button: **Save this event**

**Expected impact:** make the next action feel like completing something the user already owns, while giving a newly registered user one obvious next step. Measure signup-to-first-saved-event within 24 hours, first-session saves, and 7-day return visits. No uplift estimate is justified until instrumentation exists.

**Guardrail:** describe saved events as an organized shortlist. Do not frame them as price tracking or promise alerts.
