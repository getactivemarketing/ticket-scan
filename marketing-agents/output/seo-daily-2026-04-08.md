**Remaining venue schema gaps (from 04-07):**

## 4. Live Site Validation (New Findings)

Fetched live pages to validate rendered output:

### Duplicate Title Tag on Venue, City, and Category Pages
**Issue:** `/venues/msg` renders title as `"Madison Square Garden Tickets - Compare Prices | Ticket Scan | Ticket Scan"` — the site name suffix is appended **twice**. The `generateMetadata` title includes "| Ticket Scan" AND the layout template `%s | Ticket Scan` adds it again.

**Affected files (56 pages total):**
- `web/src/app/venues/[slug]/page.tsx:34` — 24 venue pages
- `web/src/app/tickets/[slug]/page.tsx:60` — 21 city pages
- `web/src/app/tickets/[slug]/page.tsx:65` — 11 category pages

**Impact:** High. Duplicate suffixes look spammy to both users and search engines, waste title tag character budget on 56 SEO pages.

**Fix:** Remove `| Ticket Scan` from all three `generateMetadata` titles. Let the layout template `%s | Ticket Scan` handle the brand suffix.

### No Canonical Tags Rendered
**Issue:** No `<link rel="canonical">` tag found on any checked page (homepage, venues, World Cup). Without canonicals, search engines may index both `www.ticketscan.io` and `ticketscan.io` as separate pages.

**Note:** Next.js `metadataBase` should auto-generate canonicals, but they don't appear in the live output. Needs investigation — may need explicit `alternates.canonical` in metadata.

### Missing og:image Across All Pages
**Issue:** No `og:image` tag on any page. Social shares (Twitter, Facebook, LinkedIn, Slack) will have no preview image.

**Recommendation:** Add a default OG image in the root layout and page-specific images for high-traffic pages.

### World Cup Twitter Tags Use Generic Fallback
**Issue:** `/world-cup-2026` Twitter card title falls back to generic "Ticket Scan - Compare Ticket Prices" instead of the WC-specific title. Confirms the `'use client'` metadata gap.
