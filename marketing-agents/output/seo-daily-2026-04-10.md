## Technical Fixes Applied

### 1. Blog Fake FAQ Schema Removed (HIGH PRIORITY)
- **File:** `web/src/app/blog/[slug]/page.tsx`
- **Issue:** Every blog post emitted a `FAQPage` schema with auto-generated questions from tags (e.g., "How to find cheap concerts?") with canned one-line answers. This is thin/spammy structured data.
- **Risk:** Google manual action for misleading structured data.
- **Fix:** Removed the entire `faqJsonLd` block. Only the legitimate `Article` schema remains.

### 2. Venue Country Code Fixed (MEDIUM PRIORITY)
- **File:** `web/src/app/venues/[slug]/page.tsx`
- **Issue:** `addressCountry` hardcoded to `'US'` for all venues, including Scotiabank Arena in Toronto, Canada.
- **Fix:** Now checks venue state against Canadian province codes and sets `CA` accordingly.
