## Technical Fix Applied

**Issue:** World Cup 2026 main page (`/world-cup-2026/page.tsx`) was entirely a `'use client'` component.

**Impact:** 
- Google could not read server-rendered metadata (title, description, OG tags)
- No structured data for rich results
- Page fell back to default template title in SERPs
- This is the site's highest-traffic seasonal landing page (57 days until tournament)

**Fix:**
1. Created `WorldCupSchedule.tsx` — extracted interactive schedule filtering (useState) into a dedicated client component
2. Rewrote `page.tsx` as a server component with:
   - Full `Metadata` export (title, description, 8 keywords, OG, Twitter)
   - `SportsEvent` JSON-LD with 16 venue locations
   - `BreadcrumbList` JSON-LD
3. Build verified: 115/115 pages generate, World Cup page now static

**Files changed:**
- `web/src/app/world-cup-2026/page.tsx` — Rewritten as server component
- `web/src/app/world-cup-2026/WorldCupSchedule.tsx` — New client component (extracted)
