## Technical Fix Applied

**Fix:** Added `FAQPage` JSON-LD schema to homepage.

**Implementation:**
- Lifted the 3-FAQ array to a module-level `homepageFaqs` constant in `web/src/app/page.tsx` so the rendered HTML and JSON-LD schema share a single source of truth
- Converted the homepage JSON-LD block to a `@graph` container holding both the existing `WebSite` entity and a new `FAQPage` entity, each with a stable `@id`
- Each FAQ maps to a `Question` with `acceptedAnswer` → `Answer` → `text`, per Google's FAQPage rich-result spec

**Why this matters:**
- FAQ rich snippets expand SERP real estate 3-5x for ranked terms
- Three core TicketScan positioning questions (free to use, how we save you money, supported event types) now eligible to render as SERP expandables
- Single source of truth prevents display/schema drift — if an FAQ is edited later, both the HTML and the schema update together

**Files changed:**
- `web/src/app/page.tsx` — Added `homepageFaqs` constant, expanded JSON-LD to `@graph` format with `WebSite` + `FAQPage`, refactored FAQ render loop to consume the same constant

**Verification:**
- `npm run build` → 115/115 routes compiled, no errors
- `grep FAQPage` in built `index.html` → confirmed schema present in server-rendered output
