## Technical Fix Applied

**Fix:** Added `web/src/app/dashboard/layout.tsx` — a server-component layout that wraps the client-side dashboard page to provide page-specific `metadata` and JSON-LD. Directly parallels the `/compare/layout.tsx` pattern shipped 2026-04-19.

**What it ships:**

1. **`metadata` export:**
   - `title`: "Search Events & Track Ticket Prices — Dashboard" — wraps under root template → rendered as `"Search Events & Track Ticket Prices — Dashboard | Ticket Scan"` (targets head-terms "search events", "track ticket prices")
   - `description`: explicit mention of "Ticketmaster", "SeatGeek", "filter by city, date, or keyword", "price alerts" — matches real user queries for event-search workflows
   - `keywords`, `alternates.canonical: https://ticketscan.io/dashboard`
   - OpenGraph + Twitter cards matching

2. **JSON-LD `@graph` with two entities:**
   - `WebApplication` (`@id: ticketscan.io/dashboard#webapp`)
     - `applicationCategory: 'BusinessApplication'`, `operatingSystem: 'Web'`, `browserRequirements` set
     - `offers: { price: '0', priceCurrency: 'USD' }` — signals free tool (required for `WebApplication` rich-result eligibility)
     - `featureList: [...]` — 5 bullets: multi-source search, city/keyword/date filter, one-click watchlist, price-drop alerts, buy/wait/hold recommendations
     - `provider` → Organization `@id`, `isPartOf` → `ticketscan.io/#website`
   - `BreadcrumbList` (`@id: ticketscan.io/dashboard#breadcrumbs`) — Home → Search Events

**Why `WebApplication` again:** Same reasoning as `/compare` — `/dashboard` is an interactive tool (search inputs → API call → rendered results) and `WebApplication` is Schema.org's canonical type for web-based software utilities. Consistency also helps: two of our top-nav product pages now emit parallel `WebApplication` entities, which reinforces the entity graph for the Ticket Scan organization.

- `npm run build` → **115/115 routes compiled**, no errors

  - `<title>Search Events &amp; Track Ticket Prices — Dashboard | Ticket Scan</title>` ✓
  - `canonical href="https://ticketscan.io/dashboard"` ✓
  - `"@type":"WebApplication"` ✓, `"@type":"BreadcrumbList"` ✓, `"@type":"Offer"` ✓
  - `@id` values `ticketscan.io/dashboard#webapp` + `ticketscan.io/dashboard#breadcrumbs` present ✓
