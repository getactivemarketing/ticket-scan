## 1. Index & Crawl Health (verified from source)

- **`robots.ts`** — ✅ Allows `/`; disallows `/watchlist`, `/event/`, `/api/`,
  `/admin`. Sitemap referenced (`https://ticketscan.io/sitemap.xml`).
  - ⚠️ Minor: `/favorites` is **not** disallowed. If it's a logged-in-only page
    with no indexable content, consider adding it to `disallow` to save crawl
    budget. Low priority.
- **`sitemap.ts`** — ✅ Generates URLs dynamically from `venues`, `cities`,
  `categories`, blog posts, and World Cup venues, so new entries auto-appear.
- **Canonicals / metadata** — ✅ `metadataBase` set sitewide in `layout.tsx`;
  per-page `generateMetadata` present across templates (18 files).

### Low-priority enhancement flagged (not changed today)
`sitemap.ts` sets `lastModified = new Date()` for every static, venue, city,
category, and World Cup URL. This stamps *every* URL as "modified now" on each
deploy, which trains Google to discount the `lastmod` signal. Blog posts already
do this correctly (`new Date(post.updatedAt || post.publishedAt)`).
**Recommendation:** give venues/cities/WC a real per-entity reviewed date
instead of `new Date()`. Low effort, restores a real freshness signal. Queued,
not auto-applied.
