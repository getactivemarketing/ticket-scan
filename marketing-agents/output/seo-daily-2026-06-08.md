## 2. Technical fix applied this run

### Fix — missing self-referencing canonicals on 5 indexable static pages

- **Found:** the root layout sets `metadataBase: new URL("https://www.ticketscan.io")`
  (`layout.tsx:41`), but **no page-level `alternates.canonical`** on the static core
  pages. In Next.js, `metadataBase` only resolves *relative* URLs for OG/canonical —
  it does **not** emit a `<link rel="canonical">` by itself. So these pages shipped
  with **no canonical tag at all**:
  | Page | Before | After |
  |---|---|---|
  | `/` (`page.tsx:13`) | no canonical | `https://www.ticketscan.io` |
  | `/faq` (`faq/page.tsx:4`) | no canonical | `…/faq` |
  | `/how-it-works` (`how-it-works/page.tsx:4`) | no canonical | `…/how-it-works` |
  | `/blog` (`blog/page.tsx:6`) | no canonical | `…/blog` |
  | `/world-cup-2026` (`world-cup-2026/page.tsx:6`) | no canonical | `…/world-cup-2026` |

- **Why it matters (not cosmetic):** the marketing agents append UTM params heavily
  (`?utm_source=…`, plus inbound `gclid`/`fbclid` from any future paid/social). With
  **no** self-referencing canonical, every tagged variant of these URLs is a crawlable
  duplicate that splits ranking signals. This is most acute on **`/world-cup-2026`**
  (sitemap priority 0.9, kickoff in 3 days, the page most likely to receive
  campaign-tagged inbound traffic). A self-canonical consolidates all variants to the
  clean URL.

- **Verified the gap was real, not handled elsewhere:** `grep` for `canonical`/
  `alternates` across all page templates → the 4 dynamic templates
  (`blog/[slug]`, `world-cup-2026/[stadium]`, `venues/[slug]`, `tickets/[slug]`)
  **already** declared `alternates.canonical`; only the 5 static pages above did not.
  So this completes the pattern rather than introducing a new one.

- **Fix:** added `alternates: { canonical: '<absolute-url>' }` to each page's
  `metadata` block (absolute URLs, matching the dynamic-template convention; placed
  right after `keywords`, before `openGraph`). Metadata-only — no runtime/render
  logic touched.

- **Verification:**
  - Canonical coverage recheck across all 9 indexable page types → **all HAS canonical**.
  - `npx tsc --noEmit` → **exit 0**.
  - Not committed (git discipline — push only when asked).
