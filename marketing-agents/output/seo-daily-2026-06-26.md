## 4. Open Issues Requiring Human Decision

### Issue A: Login-gated pages in sitemap (HIGH PRIORITY)
**Files:** `web/src/app/sitemap.ts` lines 31–43

`/dashboard` (priority 0.9) and `/compare` (priority 0.8) are both included in `sitemap.xml` as high-priority pages.

- `/compare` hard-redirects anon visitors to `/login` (confirmed in memory log).
- `/dashboard` likely does the same.

**Impact:** Googlebot fetches these URLs from the sitemap and encounters redirects to `/login`. Google cannot index the actual content, wasting daily crawl budget on high-priority entries that return no indexable content. This is a crawl signal mismatch — sitemap says "crawl often, high value" but the response is "you can't see this."

**Options (requires team decision):**
1. Remove both from sitemap — cleanest; signal matches reality.
2. Add `robots: { index: false }` metadata to those pages — prevents indexing but wastes crawl.
3. Un-gate `/compare` for anon users (already a known CRO P0 per memory) — ideal long-term; addresses both SEO and conversion.

### Issue B: World Cup SportsEvent missing `image` in schema (LOW PRIORITY)
Google requires an `image` property on Event/SportsEvent for rich result eligibility. No OG image is currently declared in the SportsEvent schema.

**Recommendation:** When a WC 2026 OG banner is generated, add it to the SportsEvent node:
```javascript
image: 'https://www.ticketscan.io/og/world-cup-2026.jpg',
```
