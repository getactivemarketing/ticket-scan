## 3. Technical Fix Applied

### Fix: WC stadium SportsEvent `image` + `@id` cross-reference — FIXED

**File:** `web/src/app/world-cup-2026/[stadium]/page.tsx` lines 79–114

**Problem (carried from 2026-06-27):** `SportsEvent` nodes on all 16 WC stadium pages were missing `image`, a required field for Google's Event rich result. Additionally, `SportsEvent.location` was declared as a new inline `Place` node rather than a cross-reference to the outer `StadiumOrArena` — missing the graph-linking benefit.

**Changes made:**

1. Added `'@id': \`https://www.ticketscan.io/world-cup-2026/${stadium}#place\`` to the `StadiumOrArena` node — enables cross-referencing.

2. Added `image: 'https://www.ticketscan.io/logo.png'` to the `SportsEvent` node — satisfies Google's required field for Event rich results. This is a functional fallback; a proper WC-themed OG image at `/og-world-cup-2026.jpg` would improve click-through rates on rich results. Filed as a creative asset request below.

3. Changed `SportsEvent.location` from `{ '@type': 'Place', name: venue.name }` to `{ '@id': \`.../${stadium}#place\` }` — links the event to the outer venue node, consistent with the pattern used on `/venues/[slug]` pages.

**Impact:** All 16 WC stadium pages are now eligible for Google's Event rich result feature. No functional change to rendered UI.
