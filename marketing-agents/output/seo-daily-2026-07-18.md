## Technical Fix Applied Today

### Fix: Added `image` to `HowTo` Schema on `/how-it-works`
**File:** `web/src/app/how-it-works/page.tsx`

**Why:** Google's `HowTo` rich results documentation lists `image` as a recommended (not required) property. Including it:
1. Makes the schema eligible for `HowTo` SERP features that display imagery alongside steps
2. Consistent with other pages in the codebase (blog posts, WC pages all use the logo as fallback image)

**Change:** Added `image: 'https://www.ticketscan.io/logo.png'` to the `HowTo` node, matching the fallback image pattern used on blog posts and WC stadium pages.

**Before:**
```javascript
name: 'How to Compare Ticket Prices with Ticket Scan',
description: '...',
step: steps.map(...),
```

**After:**
```javascript
name: 'How to Compare Ticket Prices with Ticket Scan',
description: '...',
image: 'https://www.ticketscan.io/logo.png',
step: steps.map(...),
```

No sitemap bump needed (this change is on a utility/info page, not a data file revision).
