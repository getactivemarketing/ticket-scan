1. **Stale sitemap revision date (fixed in source).** `web/src/app/sitemap.ts`
   reported `2026-08-24` for programmatic content even though the venue data
   set was materially updated on 2026-09-30. Updated
   `CONTENT_LAST_MODIFIED` to `2026-09-30`. This will appear on the live
   sitemap after the next deployment.
2. **Build failure unrelated to today's change.** `npm run build` compiled and
   passed TypeScript, then failed while prerendering
   `/teams/air-force-academy-falcons-football` because the deployed API
   returned HTTP 500 for attraction `K8vZ91758IV`. This needs investigation
   before the next production deploy.
3. **Existing lint failures.** `npm run lint` reports errors in
   `web/scripts/venue-cleanup.js` (`require()` imports) and
   `web/src/app/layout.tsx` (`@ts-ignore`), plus eight warnings. These were
   not changed because they are outside the sitemap fix.
