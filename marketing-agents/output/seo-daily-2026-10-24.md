   pages sampled by search and direct fetch still contain variants of “Track
   Price,” “Track prices,” “Get alerts when prices drop,” and “price history.”
   This conflicts with the current product status: TicketScan is presently an
   event-discovery, venue-guide, listing-link, and onsale-date product. The
   current local source includes status-safe tests, so this looks like deployed
   build drift or stale ISR output. Rebuild/redeploy the current frontend and
   purge/revalidate affected pages before the next crawl.

2. **Medium — stale SEO positioning in category metadata.** Category pages used
   the title suffix “Best Prices,” which overpromises while price tracking is
   unavailable. The local source now uses “Schedules and Onsale Dates.” This
   change still needs deployment verification.

3. **Low — ranking and indexing telemetry gap.** Connect the daily run to a
   Search Console export/API so indexed count, query positions, crawl errors,
   and >5-position changes can be reported instead of marked unverifiable.
