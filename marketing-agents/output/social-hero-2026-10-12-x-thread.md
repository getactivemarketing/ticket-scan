## Thread copy

**1/8**

“Playoff tickets” is not one event.

Game 1, Game 5 if necessary, and a placeholder listing can look similar in search results. They are not interchangeable.

Here’s the five-minute check before you buy:

**2/8**

Start with the official schedule.

Write down:

- series and round
- game number
- home team and venue
- local date and start time
- confirmed, scheduled, or conditional status

If the listing cannot answer those, stop comparing.

**3/8**

“If necessary” is doing a lot of work.

A potential Game 5 may only happen if the series reaches that point. A listing for a conditional game can carry different cancellation and delivery terms from a confirmed game.

Read the condition. Don’t infer it from the countdown timer.

**4/8**

Two listings on the same date can still be different events.

Check the game number, venue, opponent status, and local start time—not just the team name and Friday/Saturday label.

Same date ≠ same ticket.

**5/8**

Then read fulfillment language:

- When will the ticket arrive?
- Is it mobile transfer or pickup?
- Does the seller already have it?
- Are there transfer restrictions?
- What happens if the game is not played?

“Guaranteed” is not a complete explanation.

**6/8**

Only after the event matches should you compare the listing itself:

1. Same ticket quantity
2. Similar section and view
3. Same delivery expectation
4. Complete checkout total
5. Buyer-protection and refund terms

Headline numbers are not enough.

**7/8**

TicketScan can help with the research step: find the event, confirm the venue, and open the relevant venue guidance.

Before payment, confirm the exact event on the seller’s page and keep the order terms.

**8/8**

The calm playoff-ticket workflow:

**Identify the event → verify the condition → read delivery terms → compare like with like → review the final checkout screen.**
